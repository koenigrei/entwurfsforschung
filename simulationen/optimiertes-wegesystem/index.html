Ausgehend vom Modell „Path System 02“ (zehn Home Cells, eine Center Cell, markierter Heimweg) wird hier untersucht, welche Einstellungen für angle threshold und wiggle threshold am wirksamsten sind. Jeder Agent trägt eigene Werte, anfangs zufällig zwischen 0 und 179°, als Chromosom aus zweimal acht Bit.

Die Wirksamkeit wird daran gemessen, wie oft ein Agent den Weg von seiner Home Cell zur Center Cell und wieder zurück findet. Jeder Agent hat einen begrenzten Energievorrat (100 000), der sich mit jeder Bewegung erschöpft: Straßen (Zellen über dem visibility threshold) kosten mark strenght / 2, freies Feld auf dem Heimweg mark strenght, bei der Suche das Dreifache. Ist die Energie verbraucht, wird der Agent mit den „gekreuzten“ Einstellungen der erfolgreichsten Agenten seiner Familie (gleiche Home Cell) wiedergeboren: Zwei Eltern werden nach ihrem Erfolg per roulette wheel gewählt, ihre Chromosomen an einem zufälligen Punkt gekreuzt. Die mutation rate kann das System aus einem lokalen Optimum „herausschubsen“, indem einzelne Bits umgedreht werden.

Es ergibt sich eine komplexe Wechselwirkung zwischen der von den Agenten erzeugten Wegestruktur und den von dieser Struktur abhängigen besten Bewegungsparametern. Abhängig von den zufälligen Anfangswerten entsteht ein Wegesystem, dessen Vernetzung aus der sparsamen Verwendung der verfügbaren Energie folgt. Mit gleicher Lage der Home Cells (voreingestellt) und anderer Saat ergeben sich jeweils andere Werte für angle und wiggle threshold – und doch wiederholen sich manche Strukturelemente. Die App ist eine Neuumsetzung von 333_OptiWege („Network 01“, gleicher Quellcode wie 39_evoNet) von Reinhard König, nach F. Schweitzer: Brownian Agents and Active Particles (2003). Was geändert wurde, steht in QUELLE.md.

Building on the model “Path System 02” (ten home cells, one center cell, marked way home), this program examines which settings of angle threshold and wiggle threshold work best. Each agent carries its own values, initially random between 0 and 179°, as a chromosome of two times eight bits.

Efficiency is measured by how often an agent finds the way from its home cell to the center cell and back. Each agent has a limited energy reserve (100,000) that is used up step by step: roads (cells above the visibility threshold) cost mark strenght / 2, open ground on the way home mark strenght, three times that while searching. When its energy is exhausted, the agent is reborn with the “crossed” settings of the most successful agents of its family (same home cell): two parents are chosen by roulette wheel according to their success and their chromosomes are crossed at a random point. The mutation rate can “nudge” the system out of a local optimum by flipping single bits.

A complex interplay arises between the path structure generated by the agents and the movement parameters that work best on this structure. Depending on the random initial values, a path system emerges whose network follows from the economical use of the available energy. With the same home cell layout (the default) and another seed, different values of angle and wiggle threshold result each time – and yet some structural elements recur. The chart shows the averages over 50,000 steps.
