Ein eindimensionaler zellulärer Automat mit zwei Zuständen (D = 2), der Nachbarschaft aus linker Zelle, Zelle und rechter Zelle (K = 3) und N = 202 Zellen schreibt sein Muster Zeile für Zeile von oben nach unten. Der Regelcode legt für jedes der acht Muster 111 110 101 100 011 010 001 000 den neuen Zustand fest; 00011110 ist Wolframs Regel 30. Die erste Zeile beginnt entweder mit einer einzelnen Zelle in der Mitte, D101(0) = 1, oder mit einer zufälligen Folge.

Elementare zelluläre Automaten erzeugen Muster mit einem veränderlichen Grad an Zufälligkeit. In einer zufälligen Folge treten alle 2X möglichen Teilfolgen der Länge X (Korrelationslänge) gleich häufig auf; Abweichungen deuten auf Ordnungsstrukturen. Mit den Häufigkeiten pi der 16 Teilfolgen aus X = 4 nebeneinanderliegenden Zellen misst die App für jede Zeile die metrische und die topologische Shannon-Entropie:

Smet = −1/X · Σi pi · log2 pi Stop = 1/X · log2(Zahl der vorkommenden Teilfolgen)

Beide liegen zwischen 0 und 1, 0 ≤ Smet ≤ Stop ≤ 1. Regel 30 bleibt nahe 1 (chaotisch), Regel 90 zeichnet das Sierpinski-Dreieck mit schwankender Entropie, Regel 136 stirbt aus (0). Nach Alfred W. Hübler: Statistical Properties of Cellular Automata (2002). Was am Originalprogramm geändert wurde, steht in QUELLE.md.

A one-dimensional cellular automaton with two states (D = 2), a neighbourhood of left cell, cell and right cell (K = 3) and N = 202 cells writes its pattern row by row from top to bottom. The rule code sets the new state for each of the eight patterns 111 110 101 100 011 010 001 000; 00011110 is Wolfram's rule 30. The first row starts either with a single cell in the middle, D101(0) = 1, or with a random sequence.

Elementary cellular automata produce patterns with a varying degree of randomness. In a random sequence all 2X possible subsequences of length X (correlation length) occur equally often; deviations indicate ordered structures. From the frequencies pi of the 16 subsequences of X = 4 adjacent cells the app measures the metric and the topological Shannon entropy of every row:

Smet = −1/X · Σi pi · log2 pi Stop = 1/X · log2(number of occurring subsequences)

Both lie between 0 and 1, 0 ≤ Smet ≤ Stop ≤ 1. Rule 30 stays close to 1 (chaotic), rule 90 draws the Sierpinski triangle with fluctuating entropy, rule 136 dies out (0). After Alfred W. Hübler: Statistical Properties of Cellular Automata (2002). Changes to the original program are listed in QUELLE.md.
