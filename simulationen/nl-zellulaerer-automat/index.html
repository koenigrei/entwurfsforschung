Ein zweidimensionaler zellulärer Automat: Jeder Patch ist leer (state 0) oder besetzt (state 1). In jedem Schritt zählt jeder Patch die besetzten Patches seiner Moore-Nachbarschaft, counter = Σ state der acht Nachbarn, und alle wechseln danach gleichzeitig ihren Zustand. Vier Regler bestimmen die Regeln: genA und genB gelten für besetzte Zellen, genC und genD für leere.

Im Programm stirbt eine besetzte Zelle, wenn genA ≤ counter ≤ genB, und eine leere wird geboren, wenn genC ≤ counter ≤ genD. Mit den Voreinstellungen 1, 8, 1, 8 und einer anfänglichen Dichte von 1 % wechseln besetzte und leere Zellen ständig ihre Rolle; aus den verstreuten Keimen wächst ein Labyrinth aus ein Patch breiten Linien, das von Schritt zu Schritt zwischen Bildern hin- und herschaltet. setup-blank beginnt mit einer einzigen Zelle in der Mitte und erzeugt konzentrische Quadrate.

Die Fassung „12 Buildings Structure“ (2007) verknüpft die Todesregel mit „oder“: Eine Zelle stirbt, wenn sie überfüllt (counter ≥ genA, voreingestellt 7) oder vereinzelt ist (counter ≤ genB, 0); geboren wird bei 1 bis 3 Nachbarn. Aus einer zufälligen Verteilung mit 50 % entsteht in wenigen Schritten ein stabiles Muster aus Zeilen und Höfen – ein Ergebnis, mit dem sich eine Fläche mit Gebäuden füllen lässt. Die Kennzahlen „greens“, „blues“ und „ratio-blue / all cells“ messen wie im Original den Anteil der bebauten Zellen. Per Klick lassen sich Zellen setzen und löschen.

Die App ist eine Neuumsetzung von celluAutomata03.nlogo („02_cellular Automata“, 2005) und CA_buildingStructure.nlogo („12_Buildings Structure“, 2007) von Reinhard König. Was geändert wurde, steht in QUELLE.md.

A two-dimensional cellular automaton: each patch is empty (state 0) or occupied (state 1). In every step each patch counts the occupied patches of its Moore neighbourhood, counter = Σ state of the eight neighbours, and then all of them change their state at once. Four sliders set the rules: genA and genB apply to occupied cells, genC and genD to empty ones.

In the program an occupied cell dies if genA ≤ counter ≤ genB, and an empty one is born if genC ≤ counter ≤ genD. With the defaults 1, 8, 1, 8 and an initial density of 1 %, occupied and empty cells keep swapping roles; the scattered seeds grow into a maze of lines one patch wide that switches back and forth between images from step to step. setup-blank starts with a single cell in the centre and produces concentric squares.

The version “12 Buildings Structure” (2007) links the death rule with “or”: a cell dies if it is overcrowded (counter ≥ genA, default 7) or isolated (counter ≤ genB, 0); a cell is born with 1 to 3 neighbours. From a random distribution of 50 %, a stable pattern of rows and courtyards emerges within a few steps – a result that can be used to fill an area with buildings. As in the original, the measures “greens”, “blues” and “ratio-blue / all cells” give the share of built-up cells. Click to set and clear cells.

The app re-implements celluAutomata03.nlogo (“02_cellular Automata”, 2005) and CA_buildingStructure.nlogo (“12_Buildings Structure”, 2007) by Reinhard König. Changes are listed in QUELLE.md.
