autoCAD VBA experimente
Kontakt: Reinhard König

Autocad Visual Basic for Applicatons ist eine einfach zu erlernende Programmierumgebung innerhalb von Autocad. Der Vorteil gegenüber anderen Script-Sprachen ist, dass hier in einer 3D Umgebung gearbeitet werden kann und die Ergebnisse gleich in einem CAD Programm verfügbar sind.
Die ersten Experimente mit autoCAD_VBA sind auf diesen Seiten mit dem Quellcode dokumentiert, der per copy and paste in den Visual Basic Editor in Autocad copiert werden kann.

 

01
2Dwachstum01 - erste Versuche zu Wachstumsstrukturen (über einen Zufallsgenerator erzeugt)
2Dwachstum02 - weiterbearbeite Struktur
2Dwachstum03 - wander Würfel
2Dwachstum04 - playing around with some scaling, rotating and more

02
Rekursive Strukturen01 - Verzweigungsstrukturen
Rekursive Strukturen02 - dreidimensionale Wachstumsstrukturen
Rekursive Strukturen03 - Strukturen mit Höhenstaffelung

03
objectCoordinates - Manipulation der Object-Vertices

04
convexHull - Hülle um beliebig verteilte Punkte

05
eingabefeld - Parameter über Eingabefeld steuern (Userinterface)

06
nodeGarden - Interaktion von 'nodes', die sich innerhalb eines festgelegten Rahmens bewegen.

die VBA Experimente waren die Grundlage zu der Arbeit ,Computergenerierte Stadtstrukturen'
