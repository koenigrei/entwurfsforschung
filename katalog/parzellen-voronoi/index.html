Parzellen aus Voronoi-Zellen: Punkte in gleichem Abstand auf dem Blockrand erzeugen Zellen, die alle an der Straße liegen; kurze Zellgrenzen werden zu ruhigeren Grenzen zusammengezogen.

Das Verfahren hat drei Phasen, die hier je ein Schritt sind. Divide Distance setzt ab der ersten Blockecke Punkte auf den Blockrand, jeder im geraden Abstand Cell Distance zum vorigen. Voronoi teilt den Block so, dass jede Stelle zum nächstgelegenen Punkt gehört; Trim with Region schneidet die Zellen am Block ab. Weil alle Punkte auf dem Rand liegen, berührt jede Zelle die Straße – „Keeps each parcel connected to the street“.

Voronoi-Zellen haben oft kurze, unruhige Grenzstücke. Network Smooth zieht sie zusammen: Innere Ecken, die näher als Schwelle = Cell Distance × Snapping beieinanderliegen, werden zu einer Ecke; liegt eine Ecke so nahe an einem Anker – einer Blockecke oder einem Punkt, an dem eine Zellgrenze den Rand trifft –, springt sie auf den Anker. Die Randecken bleiben fest, deshalb behält jede Parzelle ihren Straßenanschluss.

Probieren: Cell Distance zwischen 10 und 100 m verändern – kleine Werte ergeben schmale, tiefe Parzellen, große Werte wenige große. Snapping auf 0,5 stellen und die gestrichelten ungeglätteten Zellen mit den geglätteten vergleichen; das Glätten ausschalten.

Die App setzt das Modul „Parcellation via Voronoi“ aus dem Parametric Planning Catalogue (DeCodingSpaces, InfAR, Bauhaus-Universität Weimar, 2020, MIT-Lizenz) neu im Browser um. Was geändert wurde, steht in QUELLE.md.

Parcels from Voronoi cells: points at equal distance on the block edge generate cells that all touch the street; short cell borders are snapped together into calmer borders.

The method has three phases, each one step here. Divide Distance places points on the block edge starting at the first corner, each at the straight distance Cell Distance from the previous one. Voronoi divides the block so that every location belongs to the nearest point; Trim with Region clips the cells to the block. Since all points lie on the edge, every cell touches the street – “Keeps each parcel connected to the street”.

Voronoi cells often have short, ragged border pieces. Network Smooth pulls them together: inner vertices closer than threshold = Cell Distance × Snapping to each other become one vertex; if a vertex is that close to an anchor – a block corner or a point where a cell border meets the edge – it jumps onto the anchor. Edge vertices stay fixed, so every parcel keeps its street access.

Try: change Cell Distance between 10 and 100 m – small values give narrow, deep parcels, large values few big ones. Set Snapping to 0.5 and compare the dashed unsmoothed cells with the smoothed ones; switch smoothing off.

The app re-implements the module “Parcellation via Voronoi” of the Parametric Planning Catalogue (DeCodingSpaces, InfAR, Bauhaus-Universität Weimar, 2020, MIT license) in the browser. Changes are listed in QUELLE.md.
